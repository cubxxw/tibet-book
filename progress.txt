## Codebase Patterns
- Use `pnpm` as package manager (not npm or yarn)
- TypeScript typecheck: `npx tsc --noEmit`
- VitePress dev server: `pnpm dev`
- Build command: `pnpm build`
- Vue components use `<script setup>` syntax
- Frontmatter props accessed via `useData()` in Vue components
- CSS variables follow `--vp-*` and `--color-*` naming conventions
- Chapter numbering uses Chinese numerals array lookup
